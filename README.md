# Deep Learning for Computer Vision — Exam Notes

This site organizes the IITM **DA5006 Deep Learning for Computer Vision** course into weekly reports, exam-focused summaries, concept notes, and worked past-paper questions.

## How to study

1. Start with the weekly report for the derivations and conceptual context.
2. Review the exam notes for equations, common traps, and rapid recall.
3. Solve the week-wise question bank, then check the worked reasoning.
4. Use the study guide and question index to prioritize revision by exam scope.

## Exam scope

- **Quiz 1 (Q1):** Weeks 1–4 only.
- **Quiz 2 (Q2):** Weeks 5–8, with some questions from weeks 1–4.
- **End Term (ET):** Weeks 1–12, with emphasis on weeks 9–12.
- Weeks 6–12 are provisional where the official syllabus is unavailable; inferred topic pages are labeled accordingly.
